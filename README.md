# দাখিল ২০১২ ব্যাচ — খুলনা আলিয়া মাদ্রাসা
## Dakhil 2012 Batch Portal & Fund Management System

একটি আধুনিক, ১০০% সার্ভারলেস এবং পূর্ণাঙ্গ ডিজিটাল স্বচ্ছতার সমন্বয়ে নির্মিত ব্যাচ পোর্টাল ও কল্যাণ ফান্ড ব্যবস্থাপনা প্ল্যাটফর্ম।

---

### ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **পাবলিক ল্যান্ডিং ও লাইভ স্বচ্ছতা (Public Transparency)**:
   - লাইভ আর্থিক পরিসংখ্যান: মোট সক্রিয় তহবিল, সংগৃহীত চাঁদা, কল্যাণ সহায়তায় মোট ব্যয় এবং বর্তমান নিট তহবিল স্থিতি।
   - চলমান তহবিলের প্রগ্রেস বার এবং শর্ত ও নীতিমালা (শর্তাবলী)।
   - জরুরি নোটিশ টিকার (Marquee Announcement Bar)।
   - খুলনা আলিয়া ২০১২ ব্যাচের স্মৃতিকথা ও ফটো অ্যালবাম।

2. **ব্যাচমেট ডিরেক্টরি (`/members`)**:
   - সকল সহপাঠীর নাম, ইমেইল ঠিকানা, মোবাইল নম্বর, বর্তমান পেশা, কর্মস্থল এবং জরুরি রক্তের গ্রুপ ফিল্টার।
   - রক্তের গ্রুপ অনুযায়ী এক ক্লিকে ডোনার খোঁজার সুবিধা।

3. **অফিসিয়াল নোটিশ বোর্ড (`/notices`)**:
   - ক্যাটাগরিভিত্তিক নোটিশ (জরুরি বিজ্ঞপ্তি, সভা আহ্বান, সাধারণ বার্তা)।
   - শীর্ষে পিন করার সুবিধা।

4. **সদস্য ড্যাশবোর্ড (`/dashboard`)**:
   - ব্যক্তিগত চাঁদা পরিশোধের পূর্ণাঙ্গ লেজার হিস্ট্রি (যাচাইকৃত বনাম অপেক্ষমান)।
   - যেকোনো তহবিল বেছে নিয়ে নতুন চাঁদা বা অনুদান এন্ট্রি দেওয়ার সুবিধা (বিকাশ, নগদ, ব্যাংক, ক্যাশ)।
   - প্রতি মাসের অঙ্গীকার নির্ধারণ ও হালনাগাদ।
   - নিজস্ব প্রোফাইল ও ডিরেক্টরি তথ্য আপডেট।

5. **মিনিমালিস্ট অ্যাডমিন প্যানেল (`/admin`)**:
   - **বামপাশের কলাপসিবল সাইডবার** (Left Collapsible Sidebar Navigation)।
   - **স্প্রেডশিট-স্টাইল মাসিক লেজার ভিউ (`/admin/ledger`)**: ২ডি ডায়নামিক গ্রিড (সদস্য × মাস), দ্রুত ইনলাইন সেল এডিটিং, এক্সেল/CSV ডাউনলোড এবং প্রিন্ট সুবিধা।
   - **পেমেন্ট অনুমোদন কিউ (`/admin/payments`)**: সদস্যদের ট্রানজেকশন ১-ক্লিকে ভেরিফিকেশন ও সরাসরি নগদ জমাদান এন্ট্রি।
   - **তহবিল ব্যবস্থাপনা (`/admin/funds`)**: নতুন তহবিল তৈরি, শর্ত ও নিয়মাবলী আপডেট, ম্যানেজার নিয়োগ ও প্রত্যাহার।
   - **খরচ ও মানবিক সহায়তা বিবরণী (`/admin/expenses`)**: চিকিৎসা অনুদান, খাদ্য সহায়তা ও প্রজেক্ট খরচের ভাউচার।
   - **রোল বেসড এক্সেস কন্ট্রোল (RBAC - `/admin/members`)**: Super Admin, Fund Manager এবং Member রোল নিয়ন্ত্রণ।
   - **সম্পূর্ণ অডিট ট্রেইল ও কার্যক্রম লগ (`/admin/logs`)**: প্রতিটি পরিবর্তনের Before/After JSON Diff এবং টাইমস্ট্যাম্প।
   - **হোমপেজ সেটিংস (`/admin/settings`)**: অ্যাডমিন থেকেই সরাসরি হোমপেজ শিরোনাম, সাব-টাইটেল, ব্যানার ছবি ও রানিং নোটিশ পরিবর্তন।

6. **PWA (Progressive Web App)**:
   - মোবাইল ফ্রেন্ডলি রেসপন্সিভ ডিজাইন।
   - `manifest.json`, সার্ভিস ওয়ার্কার (`sw.js`) এবং মোবাইলে "Add to Home Screen" ইনস্টলেশন প্রম্পট।

### 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack - 100% Free Tier on Vercel)

- **Framework**: Next.js 16 (App Router, Server Actions, TypeScript)
- **Database**: Neon Serverless PostgreSQL (with Connection Pooling)
- **ORM**: Prisma Client v6
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Auth**: RBAC JWT Session Authentication (`jose` + `bcryptjs`)
- **PWA**: Service Worker Cache & Web App Manifest

### 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Local Development)

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. ডাটাবেজ পুশ ও প্রিজমা ক্লায়েন্ট জেনারেট করুন
npx prisma db push

# ৩. ডেমো ডাটা সিড করুন (সদস্য, তহবিল, লেজার, নোটিশ)
npm run seed

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে খুলুন: `http://localhost:3000`

### 🌐 Vercel-এ ডেপ্লয়মেন্টের নির্দেশিকা (Deployment on Vercel)

1. গিটহাবে আপনার রিপোজিটরি পুশ করুন:
   ```bash
   git add .
   git commit -m "feat: complete Dakhil 2012 Batch portal"
   git push origin main
   ```
2. Vercel ড্যাশবোর্ডে গিয়ে **Add New Project** ক্লিক করুন এবং রিপোসিটি ইমপোর্ট করুন।
3. Environment Variables সেকশনে নিচের ভেরিয়েবলগুলো যুক্ত করুন:
   - `DATABASE_URL`: আপনার নিয়ন ডাটাবেজ কানেকশন পুলার স্ট্রিং
   - `NEXTAUTH_SECRET`: যেকোনো ৩২ অক্ষরের সিক্রেট কি
   - `NEXTAUTH_URL`: আপনার প্রডাকশন ডোমেন (উদা: `https://dakhil2012.vercel.app`)
4. **Deploy** বাটনে ক্লিক করুন।
